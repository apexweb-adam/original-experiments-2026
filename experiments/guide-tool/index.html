Return to the task.

An original five-minute guide for picking up interrupted work. Pair it with the working focus tool. This is a practical workflow, not a treatment or a promise of higher productivity.

Before you begin

Choose one visible finish line: “send the corrected draft” is clearer than “work on the project.” Write the smallest next action, such as opening the client’s latest feedback. Pick a short work period that fits the task.

When something interrupts

Leave a return note before switching, when possible. Record where you stopped, the next physical action and any unresolved choice. Put unrelated thoughts in the parking list so they do not become a second project.

When you come back

Read the note. Confirm that the next action still makes sense. Resume for a short interval. If priorities changed, finish the old session with an honest note and start a new one.

Three concrete examples

  • Writing: “Paragraph two needs the verified date. Open the source and replace the placeholder.”
  • Admin: “Invoices 1–8 checked. Next: compare invoice 9 against the bank export.”
  • Design: “Mobile header reviewed. Next: test the menu with the long page title.”

A one-session test

Use the tool once with a real task. After returning from an interruption, note whether you could identify the next action without rereading everything. Also record when the note did not help. This is feedback, not proof of a productivity improvement.
